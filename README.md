# Garra

Atlas emocional del fútbol uruguayo. Ver [agents.md](./agents.md) para el contrato completo del
proyecto (arquitectura, sistema de skins, modelo de datos, reglas de código).

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Verificación

```bash
pnpm verify   # typecheck + lint + test + build
```
